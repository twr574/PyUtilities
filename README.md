
# PyUtilities

A set of basic utilities written in Python.

## Features

- Autosleep script `autosleep`, which sets a timer and makes a computer sleep when the timer reaches 0.
- Sticky Notes app `stickynotes`, including a save/autosave feature, font/size adjust and 'hide title bar' toggle.

## Usage

Download the repo from here, and run the associated <area>.py file.

## Requirements

- Windows 10
- Python (uses modules from Python's standard library: <https://docs.python.org/3/library/index.html>.)

## Future Work

This project consists of a series of independent coding exercises. Other basic utilities have been programmed; if time permits, these will be improved and released publicly too.

Linux support or .exe releases may also be added at a later date.
